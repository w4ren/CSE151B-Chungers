# CSE 151B Competition Submission

This repository contains our Qwen3-4B-Thinking based math competition pipeline and the single submission entry point required for Gradescope.

## Hardware and Runtime

- Main private inference run: 4x NVIDIA RTX PRO 6000 Blackwell Server Edition GPUs, 97 GB VRAM each.
- Base private 8k vLLM run: started 2026-05-31 07:04 UTC and the resumed finalization pass completed 2026-05-31 09:04 UTC.
- Additional 16k/32k ladder reruns and adapter finalization were run later on 2026-05-31 and 2026-06-01. End-to-end wall clock for the final private routing sweep was approximately overnight, about 20-24 hours including queued reruns and audits.
- Public answer-format LoRA training: one NVIDIA A30 24 GB GPU, approximately 6 minutes.

## Model and Weight Setup

The base model is:

```text
Qwen/Qwen3-4B-Thinking-2507
```

Place or download the base model where Hugging Face/vLLM can load it. The local run used the default Hugging Face cache under:

```text
.hf-cache/hub/models--Qwen--Qwen3-4B-Thinking-2507/
```

The final pipeline used these PEFT LoRA adapter directories locally:

```text
codex_added/models/qwen3_answer_format_lora_rebuilt_20260531_070427
codex_added/models/private_finalizer_lora_20260531_180513
codex_added/models/public_mcq_selector_lora_20260531_190332
```

For verification from a clean clone, upload those adapter directories to Hugging Face Hub and download them back into the same local paths, or edit the paths in the inference scripts before running. Example upload/download shape:

```bash
huggingface-cli login
huggingface-cli upload <your-user>/qwen3-answer-format-lora-rebuilt codex_added/models/qwen3_answer_format_lora_rebuilt_20260531_070427
huggingface-cli download <your-user>/qwen3-answer-format-lora-rebuilt --local-dir codex_added/models/qwen3_answer_format_lora_rebuilt_20260531_070427
```

Install dependencies:

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r codex_added/requirements.txt
```

For vLLM on the GPU machine, the local run used `.venv-vllm`; either create that environment or use any Python environment with the packages from `codex_added/requirements.txt`.

## Single Entry Point

The required function is in [run_inference.py](run_inference.py):

```python
from run_inference import run_inference

run_inference(
    data_path="data/private.jsonl",
    output_csv="codex_added/submissions/final_submission.csv",
)
```

CLI equivalent:

```bash
python run_inference.py \
  --data data/private.jsonl \
  --output codex_added/submissions/final_submission.csv
```

The function validates that the final prediction source covers every private id exactly once, then writes the standard Kaggle/Gradescope CSV with columns:

```text
id,response
```

The final prediction source used by default is:

```text
codex_added/results/final_submission_source_20260601/combined_predictions_full_private_943.jsonl
```

That file is generated by the model pipeline and contains only `id` and `response` records. It is intentionally kept out of Git along with private data, model weights, and generated submissions. If the file is absent, `run_inference()` falls back to invoking `codex_added/scripts/19_run_best_pipeline.sh`, which runs Qwen generation, LoRA finalization, reranking, post-processing, and CSV writing from `data/private.jsonl`.

For exact reproduction of the final submitted CSV, restore the final prediction source above before calling `run_inference()`. For a clean rerun from weights, leave it absent and make sure the base model and LoRA adapters are available locally.

## Final Pipeline Summary

The submitted pipeline used Qwen3-4B-Thinking-2507 for all generation and LoRA finalization. The frozen routing was:

1. Generate base raw reasoning traces on the private data with vLLM.
2. Use an 8k/16k/32k ladder for rows that hit token limits.
3. Route free-response rows through the FRQ ladder and finalizer LoRA.
4. Route multiple-choice rows through the MCQ ladder and MCQ LoRA adapter.
5. Fill the three private-only MCQ rows outside the 940-row scored holdout from the full-private rebuilt LoRA pass.
6. Write the final CSV in `data/private.jsonl` id order.

Main generation hyperparameters:

```text
raw reasoning max_new_tokens: 8192
ladder rerun max_new_tokens: 16384, then 32768 for remaining token-limit rows
raw reasoning temperature: 0.6
raw reasoning top_p: 0.95
raw reasoning top_k: 20
finalizer max_input_tokens: 4096
finalizer max_new_tokens: 64
finalizer retry max_new_tokens: 128
finalizer temperature: 0.1
vLLM dtype: float16
vLLM quantization/load format for large runs: bitsandbytes
```
